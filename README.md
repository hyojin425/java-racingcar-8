# java-calculator-precourse

## 구현할 기능 목록

### 입력

- [x] 자동차 이름 입력
- [x] 시도 횟수 입력

### 출력

- [x] 이름 입력 안내 문구 출력
- [x] 횟수 입력 안내 문구 출력
- [ ] 최종 우승자 출력
- [x] 실행 결과 출력

### 기능

- [x] 자동차 이름 구분 기능
- [x] 0 ~ 9 랜덤 숫자 추출
- [x] 4 이상인 경우 이동
- [x] 차 이동하기 
- [ ] 우승자 판별 기능

### 예외처리

- [x] 이름이 5자 이상인 경우
- [ ] 횟수 입력이 양의 정수가 아닌 경우
- [x] 동일한 이름의 자동차가 입력된 경우
